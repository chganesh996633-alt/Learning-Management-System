#  EduLearn – Learning Management System (LMS)

EduLearn is a web-based Learning Management System (LMS) developed using React and Vite. It provides a simple and interactive platform for students to access courses, manage assignments, and track their learning activities.

# Features

- **User Registration:** Allows new users to register by entering their details.
- **User Login:** Provides a login interface for registered users.
- **Dashboard:** Displays an organized overview of the learning platform.
- **Course Management:** Provides access to different courses such as Java, Python, Web Development, SQL, and AI/ML.
- **Assignment Management:** Allows students to access and submit assignments.
- **PDF Submission:** Supports PDF-based assignment submissions.
- **Submission Status:** Displays assignment submission status and grading messages.
- **Responsive Design:** Provides a user-friendly interface across different screen sizes.
- **Interactive UI:** Includes navigation, sidebar, and theme customization.

#  Technologies Used

- **React.js** – Frontend library for building user interfaces.
- **Vite** – Development server and build tool.
- **JavaScript** – Application functionality.
- **HTML5** – Web page structure.
- **CSS3** – Styling and responsive design.
- **npm** – Package management.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash
cd EduLearn
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```
